## 결정 사항
| 항목 | 결정 |
|---|---|
| 과제 선정 | 포털에서 하지 않음. 관리자가 선정 완료 엑셀(양식 v0.0 `과제·요구사항` 시트)을 올리거나 화면에서 입력, 나머지는 조회만 |
| 측정 단위 | 요구사항 × SDLC 단계(분석 AN·설계 DS·개발 DV·테스트 TS·배포 DP·운영 OP). 단위 코드 `REQ-0047-DV` |
| 엑셀 → 단계 | 행 1개 = 요구사항 1건 + 단계 1개(REQ-03 대표 업무 유형, REQ-06 기준 M/D, REF-01 첫 사람 = 담당). 단계 추가·분할은 관리자 화면 |
| 투입 공수 | 단계·일자별 **AI 도구 내**(수집값 − 감소) + **AI 도구 외**(작업 유형 A1~A8 수기). 개발자 × 요구사항 × 일자 단위 확정, 확정 후 값이 바뀌면 재확정 필요 |
| AI 시간 수집 | ① 텔레메트리(OTLP/HTTP JSON 수신 `/api/otel/v1/*`, 토큰 인증) ② 개발자 로컬 로그 JSON 업로드(`collect_ai_usage.py`). 둘 다 세션 단위 AIUSE 행으로 저장 |
| 매칭 | 세션의 브랜치·프롬프트에서 단위 코드/요구사항 ID 를 찾아 자동 배정. 못 정하면 '확인 필요'에서 개발자가 배정·나눠 배정·업무 외 처리 |
| 지표 | 투입 공수 절감률, 순절감률(인건비 + AI 비용), AI 활용률. 확정된 날만 집계. 결함·품질은 이번 범위 제외 |
| 역할 | `ADMIN`(입력·전체), `DEVELOPER`(내 담당 단계 입력·확정), `VIEWER`(조회) |
| 단가 | 등급별 M/D 단가, AI 도구별 시간당 비용, 1 M/D 시간, 측정 시작일 — 모두 설정값 |

## 화면 (4개)
1. `/` **PoC 과제 현황** — 과제 → 요구사항 → 단계 표, 진척(투입/기준 M/D), 상태 필터. 관리자: 엑셀 올리기·양식 내려받기·요구사항/단계 편집·측정 완료 지정.
2. `/effort` **투입 공수** — 왼쪽 요구사항 카드(필터: 확정 필요·측정 중·완료·대기), 오른쪽 단계 띠 + 일자 × 단계 표(AI 감소 입력, ＋AI 도구 외 8유형, 확정/수정/재확정, 기록 없는 날 추가, 모두 확정), 확인 필요 패널, AI 기록 올리기. 관리자는 담당자 필터·조회 전용.
3. `/dashboard` **측정 결과** — 필터(구분·과제·측정 중 포함), 지표 카드 3개(실제 숫자 산식), 단계 → 업무 유형 표, 과제별 표, 작업 유형별 시간, 요구사항별 원값 표.
4. `/admin` **시스템 관리** — 계정 · 확정 현황 · 수집 이력 · 변경 이력 · 코드·단가.

삭제: 과제 기입·포트폴리오·상세·선정 보드·보고서·오늘 공수·결함·데이터 수집·점검·평가 기준·코드·목표·측정 설정·AI 판정과 그 API·lib.

## 저장소 (테이블 5개 유지, 조인 없음)
- `POC_USER_MAS` 역할 체크 `ADMIN/DEVELOPER/VIEWER`
- `POC_PRJ_MAS` 과제 1행 = 과제 정보 + 요구사항·단계 JSON(`DATA_JSON`). 낙관적 동시성 `UPD_DT`
- `POC_MEAS_DAT` `KIND_CD IN ('EFFORT','CONF','AIUSE')`, `REQ_ID` 컬럼
  - EFFORT `E|단위|일자`: 감소 시간, 작업 유형별 시간, 메모
  - CONF `C|개발자|요구사항|일자`: 확정 여부·확정 시각·수정 횟수
  - AIUSE `A|출처|세션|일자`: 분, 도구, 브랜치, 자동 매칭 코드, 배정 결과(나눔 포함), 업무 외 여부, 비용
- `POC_CFG_MAS` `SETTINGS`(단가·작업 유형·업무 유형), `POC_HIST_HIS` 변경 이력

## 계산 (`lib/measure/metrics.ts` 에만)
- 단계·일: AI 도구 내 = 수집 − min(수집, 감소), 투입 = AI 도구 내 + AI 도구 외
- M/D = 투입 h ÷ 1 M/D 시간, 인건비 = M/D × 등급 단가, AI 비용 = 수집 h × 도구별 시간당 비용
- 절감률 = (기준 − 투입) ÷ 기준, 순절감률 = (기준 인건비 − 측정 인건비 − AI 비용) ÷ 기준 인건비, AI 활용률 = AI 도구 내 ÷ 투입
- 요구사항 상태: 완료(관리자 지정) / 측정 중(입력 있음) / 대기

## 속도
- 화면은 서버 컴포넌트가 서비스에서 바로 데이터를 읽어 첫 화면을 그림(클라이언트 첫 API 왕복 제거). 변경만 `api()` 후 `router.refresh()`.
- 페이지·API 수 대폭 축소, recharts·langchain 제거(차트는 SVG/CSS).
- JSON 저장소 메모리 캐시(쓰기 시 갱신).
- 사내 시연은 `npm run local`(build + start, dev 컴파일 없음).
