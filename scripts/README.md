# AI 사용 시간 수집 스크립트

Python 3.8 이상, 표준 라이브러리만 사용합니다(추가 설치 없음). 텔레메트리를 연결하지 못한 PC 에서 씁니다.
결과 JSON 은 포털 **공수 입력 > AI 사용 기록 올리기**로 올립니다. 올린 사람 계정으로 저장되므로 사용자 ID 옵션은 없습니다.

## `collect_ai_usage.py`

개발자 PC 의 Codex 세션 기록(`~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`, `CODEX_HOME` 이 있으면 그 아래)을 읽어
**세션 × 일자(KST)** 단위로 활동 시간(분)·모델별 토큰·공수 태그 후보를 뽑습니다.

```bash
# Windows
py collect_ai_usage.py --since 2026-11-01
# macOS / Linux
python3 collect_ai_usage.py --since 2026-11-01
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--since` | 전체 | 이 날짜(포함) 이후만 |
| `--codex-dir` | `~/.codex/sessions` | 로그 위치가 다를 때 |
| `--out` | `ai_sessions_<날짜>.json` | 출력 파일 |

- **활동 시간**: 기록 사이 간격을 더하되, 5분 넘게 비면 자리 비움으로 보고 5분까지만 셉니다(포털 텔레메트리 수신과 같은 규칙). 자정을 넘긴 세션은 날짜별로 나눕니다.
- **토큰**: `token_count` 이벤트의 누적값 증가분을 `turn_context` 의 모델별로 더합니다(같은 값이 반복돼도 두 번 세지 않음). 포털이 기준정보의 토큰 단가로 AI 비용을 계산합니다.
- **공수 태그 후보**: 브랜치명과 사용자가 입력한 대화에서 `DAE01-REQ0047-DV`·`REQ0047` 같은 코드 모양(하이픈·숫자 포함) 토큰만 뽑습니다. **대화 원문은 파일에 담지 않습니다.**
- 같은 세션·일자를 다시 올리면 시간·토큰만 갱신되고, 포털에서 배정·업무 외 처리한 결과는 유지됩니다.
