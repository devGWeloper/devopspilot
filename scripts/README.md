# AI 사용 시간 수집 스크립트

Python 3.8 이상, 표준 라이브러리만 사용합니다(추가 설치 없음). 텔레메트리가 연결되지 않은 PC 에서 씁니다.
결과 JSON 은 포털 **투입 공수 > AI 사용 기록 올리기**로 올립니다. 올린 사람 계정으로 저장되므로 사용자 ID 옵션은 없습니다.

## `collect_ai_usage.py`

개발자 PC 의 Claude Code(`~/.claude/projects/**/*.jsonl`)와 Codex(`~/.codex/sessions/YYYY/MM/DD/rollout-*.jsonl`) 로그를 읽어
**세션 × 일자(KST)** 단위로 활동 시간(분)과 요구사항 코드 후보를 만듭니다.

```bash
# Windows
py collect_ai_usage.py --since 2026-11-01
# macOS / Linux
python3 collect_ai_usage.py --since 2026-11-01
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--since` | 전체 | 이 날짜(포함) 이후만 |
| `--claude-dir`, `--codex-dir` | 홈 폴더 기본 위치 | 로그 위치가 다를 때 |
| `--out` | `ai_sessions_<날짜>.json` | 출력 파일 |

- **활동 시간**: 세션 안의 기록 사이 간격을 더하되, 5분 넘게 비면 자리 비움으로 보고 5분까지만 셉니다. 자정을 넘긴 세션은 날짜별로 나눕니다.
- **요구사항 코드**: 브랜치명과 사용자가 입력한 대화에서 `REQ-0047-DV`·`REQ-0047` 같은 코드만 뽑습니다. **대화 원문은 파일에 담지 않습니다.**
- 같은 세션·일자를 다시 올리면 시간만 갱신되고, 포털에서 배정·업무 외로 처리한 결과는 유지됩니다.
- 로컬 로그는 기본 30일 후 삭제됩니다. 주 1회 이상 올려 주세요.
